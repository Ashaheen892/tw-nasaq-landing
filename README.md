# دار نَسَق

صفحتا هبوط لعبايات في سلة، على مثال صفحة دار نَسَق. سلة تطلب قالبين على الأقل لأقسام صفحات الهبوط، لذلك الصفحة الكاملة اسمها نَسَق، والمختصرة اسمها وصل.

التاجر يختار القالب من قنوات البيع ثم صفحات الهبوط، ويعدّل النصوص والصور من لوحة التحكم. في صفحة منتج تفتح أزرار الشراء الشراء السريع الخاص بالصفحة. في صفحة العروض تتبع رابط الزر.

المستودع: https://github.com/Ashaheen892/tw-nasaq-landing

## نَسَق — `templates/nasaq.json`

1. رأس الصفحة
2. افتتاح التشكيلة
3. شريط العبارات
4. شبكة القصّات
5. صف الأقمشة
6. عباية الموسم
7. عدّاد العرض
8. آراء العميلات
9. أسئلة قبل الطلب
10. دعوة الختام
11. فوتر الصفحة

شريط الشراء الثابت جزء من عباية الموسم، ويظهر بعد النزول. الصور الفارغة تُرسم بشكل رملي إلى أن يرفع التاجر صوره.

## وصل — `templates/wasl.json`

صفحة أقصر للشراء المباشر: رأس الصفحة، عباية الموسم، عدّاد العرض، أسئلة قبل الطلب، دعوة الختام، ثم فوتر الصفحة.

## التطوير

```bash
pnpm install
pnpm dev
pnpm build
pnpm audit:salla
```

المعاينة المحلية: `http://localhost:5173/node_modules/.salla-temp/index.html`
